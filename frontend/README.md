# Frontend (React 18 + Vite)

Scaffold here in Phase 1:

```bash
npm create vite@latest . -- --template react
npm install
npm run dev
```

Planned structure:
```
src/
  pages/        one per agent module
  components/    shared UI (sidebar, chat panel, cards)
  lib/           supabase client, api client
  styles/        clean-light design tokens
```
UI style: clean light / professional (see PathCompanion_AI_Planning_Pack.html).
