5. Sequence — Skill-Learned Cascade (USP) Chapter 4/5

sequenceDiagram
    autonumber
    actor U as User
    participant FE as React Frontend
    participant LR as Learning Router
    participant DB as Supabase (shared memory)
    participant EV as agent_events (bus)
    participant M2 as Model 2 Skill Extractor
    participant GA as Skill Gap Agent
    participant RA as Resume Architect
    U->>FE: Mark skill "Docker" as learned
    FE->>LR: POST /learning/complete
    LR->>DB: UPDATE skills (source='learning')
    LR->>EV: INSERT {type: skill_learned}
    LR-->>FE: 200 OK (UI not blocked)
    FE-->>U: ✅ Skill saved instantly
    Note over EV,RA: Background cascade (< 30 s)
    EV->>GA: skill_learned consumed
    GA->>M2: re-extract skills for open analyses
    M2-->>GA: present / missing skills
    GA->>DB: UPDATE gap_analyses (refreshed)
    GA->>DB: UPDATE learning_plans (progress)
    EV->>RA: same event consumed
    RA->>DB: UPDATE resumes SET needs_refresh=true
    Note over U,DB: Next visit: fresh gap report + resume flag
