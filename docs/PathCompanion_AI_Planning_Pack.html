02

The 6 Agents

Each is usable on its own (standalone) or reacting to others (interconnected). Two are powered by the trained models.

Job Scout semantic match

Aggregates jobs daily from free APIs, stores 768-d embeddings, ranks with hybrid score (embedding similarity + skill overlap). Shows matched / missing skills per job.

Skill Gap Analyzer Model 2

Compares your skills vs a job/goal and produces a present-vs-missing report with importance weights. Skill detection uses the trained skill-extraction model.

Learning Resource Finder cascade trigger

Turns each gap into an ordered study path of free resources. Marking a skill “learned” emits the event that drives the cascade.

Resume Architect Model 1

Upload & parse or build in-app. The trained resume classifier auto-categorises resumes; generates ATS-tailored versions per job, export PDF.

Mock Interview & Panic Control voice

Spoken interviews (Edge-TTS + Whisper), job-specific questions, panic button with breathing exercises, anxiety tracked pre/post, full feedback report.

Career Path Planner roadmap

Maps the next roles (Intern→Lead) with per-stage skills, durations and contextual tips.

06

Build Order (16 weeks)

Matches the proposal timeline. Two phases are dedicated to the trained ML models.

1
Foundations · W1–2

Repo, Supabase schema (12 tables) + pgvector, auth + row-level security, app shell (sidebar + chat).

2
Job Scout · W3–4

Job aggregation from free APIs, 768-d embeddings, hybrid matching, job feed + detail screens.

3
ML Model 1 — Resume Classifier · W5–6

Data prep, TF-IDF baseline, DistilBERT fine-tune, evaluation, save + inference endpoint.

4
ML Model 2 — Skill Extractor · W7–8

LLM-assisted weak labelling, multi-label DistilBERT, evaluation; wire into Skill Gap agent.

5
Resume Architect + Learning · W9–10

Parse/build, classifier badge, ATS tailoring, PDF export; learning paths + cascade trigger.

6
Mock Interview · W11–12

Edge-TTS + Whisper, live voice loop, panic control, feedback report.

7
Career Path + Cascade · W13–14

Ladder + milestones, interconnected cascade end-to-end, model-inference hardening.

8
Test, evaluate & deploy · W15–16

Unit/integration/E2E tests, evaluation report (model F1 + LLM comparison), deploy to free tiers, dissertation.
